New Expediente

Field hint prototype — click the ? icons.

Prototype notes:
  • Switching EN/ES at the top now re-renders the popups to show only that language — matching the page's active locale instead of stacking both languages.
  • The switch also re-renders page labels via a small data-i18n dictionary, standing in for what I18n.locale + normal Rails view translations would do server-side.
  • Design change from the previous version: hints used to always show both languages in one panel. Now the popup content follows the page's selected locale, same as the rest of the UI. Say the word if you want the real helper/Stimulus controller updated to match this behavior.
