Prototype notes:
  • This uses the Rails-friendly Tailwind and Stimulus structure in a 1024px-wide card.
  • The fields are arranged as a responsive 2x2 grid on desktop and collapse to one column on small screens.
  • The hint window uses inline css popover style: title, body, example note, and close button.
  • To close a popover, click the close button, click outside the popover, or press the escape key.
  • In Rails, the localized help text comes from translation files instead of rendering both languages client-side.
